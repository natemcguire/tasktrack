# Project settings

Open Settings from a project board, or `/projects/{key}/settings` directly.
Save name updates the sidebar and survives reload. Concurrent edits produce a
conflict message and retain the entered name for review. The existing project
editor remains available for the brief, key and document links.

Hosted settings include People & invitations, the future home for project email
invitations. Project invitations are not enabled yet. Workspace member management
is linked separately and retains its existing account permissions.

Disposable product specifications and wireframes live in a separate scratch
repository; review links point to authenticated, project-scoped hosted previews.
